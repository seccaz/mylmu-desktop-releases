## Installation

### 1. Download
Click the download button above and save the installer file (e.g. `MyLMU-Sync-Agent-Setup-1.1.0.exe`).

### 2. Run the installer
Locate the file in your Downloads folder and double-click to run it. Follow the wizard, choose an install location, and click **Install**.

> **Windows SmartScreen:** If "Windows protected your PC" appears, click **More info** then **Run anyway**. This is expected for new unsigned apps — the app is safe.

### 3. Launch
Open from your Start Menu or desktop shortcut. The app will guide you through first-time setup.

---

## First-time setup

### 1. Connect your account
Click **Connect to MyLMU**. Your browser will open for authentication — sign in with your MyLMU account and you'll be redirected back. Status should show **Connected**.

### 2. Select your results folder
Click **Select Folder to Monitor** and navigate to your LMU results folder. The default path is:

```
C:\Program Files (x86)\Steam\steamapps\common\Le Mans Ultimate\UserData\Log\Results
```

### 3. Sync existing files
If you have existing results you want to upload, click **Sync Existing Files**, review the list, then choose **Sync All** or select specific sessions.

### 4. Configure settings
Enable **Start with Windows** if you want the agent to launch automatically on boot. From this point the app monitors your results folder and syncs new files whenever a session completes.
