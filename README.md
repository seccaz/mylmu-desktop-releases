The MyLMU (mylmu.app) Sync Agent lets you automatically upload your session data to the MyLMU platform where you can visualize and analyze all your hidden LMU performance.


Installation Instructions​

1. Download​
Click the download button above.
Save the installer file (e.g., MyLMU-Sync-Agent-Setup-1.1.0.exe).
2. Run Installer​
Locate the downloaded file (usually in your Downloads folder).
Double-click to run the installer.
Windows SmartScreen Note: If "Windows protected your PC" appears, click "More info" and then "Run anyway". This is expected for new/unsigned applications, and the app is safe.
Follow the installer wizard:
Choose the installation location (the default is usually fine).
Click "Install" and wait for the process to complete.
3. Launch​
Launch the application from your Start Menu or the desktop shortcut.
The app window will open (or be in the apps tray), guiding you to the setup process.

First-Time Setup Tutorial​

1. Connect Your Account​
Click the "Connect to MyLMU" button.
Your browser will open for authentication.
Sign in with your MyLMU account.
You will be redirected back to the app, and the Status should now show "Connected".
2. Select Results Folder​
Click "Select Folder to Monitor".
Navigate to your LMU Results folder. The default path is:
C:\Program Files (x86)\Steam\steamapps\common\Le Mans Ultimate\UserData\Log\Results
Select the folder and confirm.
The app will display the selected path.
3. Sync Existing Files​
If you have existing result files you want to upload, click "Sync Existing Files".
Review the list of new files found.
Choose "Sync All" or select specific files.
Wait for the upload to complete.
4. Configure Settings​
Enable "Start with Windows" if you want the agent to automatically launch when you boot your PC.
The app will now monitor your Results folder automatically and sync new files when races are completed
